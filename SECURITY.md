## Reporting a Vulnerability

If you discover a potential security vulnerability in this project, please report it privately through GitHub's **Private Vulnerability Reporting** feature whenever possible.

To submit a report, go to the repository's **Security and quality** tab and select **Report a vulnerability**. This allows security issues to be reported privately to the maintainers without publicly disclosing sensitive information.

If Private Vulnerability Reporting is unavailable, or if you encounter any difficulty using GitHub's reporting process, please contact us at **[security@gpustack.ai](mailto:security@gpustack.ai)**.

Please do **not** create a public GitHub issue or otherwise publicly disclose the vulnerability before the issue has been investigated and, where appropriate, a fix or mitigation has been made available.
